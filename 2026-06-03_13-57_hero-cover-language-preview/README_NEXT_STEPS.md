# Aurora Bag Supply WordPress / WooCommerce Preview

This folder contains the Buckleguy-inspired B2B procurement site structure for Aurora Bag Supply.

## Open Preview

Open `index.html` in this folder to review the homepage.

Static preview pages:

- `index.html`
- `products.html`
- `product-detail.html`
- `account.html`
- `cart.html`
- `about.html`
- `contact.html`

## Product Data Table

Use `Aurora_Product_Master_Template.csv` as the main product planning table.

Fill one product per row. Important columns:

- `SKU`
- `Product Name`
- `Category`
- `Subcategory`
- `Main Image`
- `Gallery Images`
- `Material`
- `Color`
- `Finish`
- `Size`
- `Weight`
- `MOQ`
- `Price`
- `Wholesale Price`
- `Stock Status`
- `Application`
- `Custom Logo`
- `Packaging`
- `Featured`
- `New Arrival`
- `Best Seller`
- `SEO Title`
- `SEO Description`

Use `WooCommerce_Product_Import_Draft.csv` as the first WooCommerce import draft.
